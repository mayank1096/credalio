Structuring a clean table

One idea per column, one record per row. It sounds simple, and it’s what makes everything after it work.

Before you write a single query, look at how your data is laid out. A clean table has a header row, one kind of information in each column, and one record in each row. No merged cells, no totals hiding in the middle, no notes typed next to the numbers.

Every column here answers one question: when, where, what, how much. That’s exactly how a database stores data, which is why moving from this sheet to SQL feels natural.
