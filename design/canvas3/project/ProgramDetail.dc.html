About this program

Many people can read a report but can’t yet build one or question it. This 12-week accelerator closes that gap. Each week pairs a live session with practice on real business data, so ideas are used within days. You work in small peer groups, get written feedback from instructors, and finish with a capstone you present to the cohort.

Who it’s for

Career switchersMoving into a data role from another field.
Working professionalsUsing data and AI in the job you already have.
Recent graduatesWanting structured, practical work for a portfolio.

Not designed for complete beginners. If spreadsheets are new to you, start with Data Foundations.
