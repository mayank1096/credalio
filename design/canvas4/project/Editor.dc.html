INNER vs LEFT JOIN

Chapter 3 · Joining Tables

Estimated DLP3,400 words at 230 a minute · about 15 min. Recalculated automatically when this item or its tier changes.20Estimated learning time15mAssignedAJAda + JohnRequirementRequired

Details

Title
Description

Lesson text

When you join two tables you choose which rows survive. An INNER JOIN keeps only rows that match in both tables; a LEFT JOIN keeps every row from the left table and fills the gaps with NULL.

Worked example: customers and orders

  1. Start with the customers table (who) and the orders table (what they bought).
  2. INNER JOIN on customer_id returns only customers who have ordered.
  3. LEFT JOIN returns every customer, with NULL where there is no order.
