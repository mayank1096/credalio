# Landing learner pages: client review checklist (checked 2026-11-16, canvas v206)

Each point of the client review ("Learner pages review") was checked against the rendered pages.
✓ = done and verified · ◐ = done with a note.

## Course detail
- ✓ Skills you'll develop with target level per skill
- ✓ Who this course is for: designed for, you'll need, good to have, tools, Check my readiness (Nova)
- ✓ How you'll learn: self-paced, lesson formats with counts, AI Coach, tutor, creator Q&A
- ✓ Course at a glance: format, language, captions, assessment, last updated, version
- ✓ About this course
- ✓ Assessments: attempts, pass mark, what each counts toward
- ✓ What you'll earn: completion criteria, certificate preview, "not a Professional Certification"
- ✓ FAQ + Keep learning: next course, path, certification, program
- ✓ Access card shows DLP and Credits (lifetime), "separate, not converted"
- ✓ Lesson preview screen, desktop + mobile: video with captions + transcript, title/module/length, curriculum beside it (free open, rest locked), a reading lesson, Start the course / back
  - ◐ A practice lesson has no screen of its own; it shows as a locked row in the curriculum. The review asked for "a reading or practice lesson", and the reading lesson covers that.
- ✓ Access states: not enough DLP, owned with Credits, in progress, completed, temporary, closed, subscription only
- ✓ Save and Share on the hero
